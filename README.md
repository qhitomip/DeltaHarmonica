# Delta Harmonica

一个面向《三角洲行动》玩家的 Windows MIDI 口琴演奏工具。

## 使用方式

1. 拖入或选择 `.mid` / `.midi` 曲谱；
2. 程序分析全部“音轨＋通道”并推荐主旋律；无法可靠判断时会显示音轨信息供你选择；
3. 在列表中选中曲谱并切到游戏；
4. 按启停热键开始演奏，再按一次立即停止。默认热键为 F8，可在界面改成 F6～F12。

导入后会自动转换，启动延时默认是 0 秒，可以在界面中设为 0～30 秒。默认使用 95% 速度的稳定演奏模式，也可以切换为原始时序或将速度调整到 60%～120%。

## 查找 MIDI

界面的“找 MIDI”栏可以按歌曲名或歌手搜索 [Midify](https://www.midify.cn/) 和 [MIDI云](https://www.midiclouds.com/)。从网站下载 `.mid` 或 `.midi` 文件后，把文件拖回软件即可。

## 自动处理

- 优先选择名称包含 Melody、Lead、Vocal、主旋律、主奏、人声等字样的轨道；
- 自动排除 MIDI 的鼓通道，并降低 Bass、Chord、Pad、伴奏等轨道的优先级；
- 读取 MIDI 乐器 Program、音符数量、时长、音域、单音率和密度；自动判断不够可靠时由用户选轨；
- 一个轨道中同时出现多个音时保留最高音，生成游戏需要的单音旋律；
- 保留 MIDI 中重复的同音，不会把 `5 5 5` 合并成长音；
- 自动整体移调，并通过八度调整保留每个音的音名；
- 优先使用普通音区，减少鼠标修饰键操作；
- 连续使用相同音区时保持鼠标修饰键，只切换音键。
- 稳定模式保证至少 80 毫秒按键时间和 25 毫秒松开间隔，并提前 25 毫秒切换鼠标音区，以减少游戏吞音。

转换结果、歌曲列表、倒计时和热键设置统一保存在 `%LOCALAPPDATA%\DeltaHarmonicaMidi`。这个目录与旧方案的数据完全分开。

## MIDI 选择技巧

为了获得更好的结果，优先选择带有独立 Melody、Lead、Vocal 或主旋律轨道的 MIDI。只有钢琴和弦的 MIDI 也能转换，但自动保留最高音不一定等于原曲主旋律。选中歌曲后点击“选择音轨”，可以查看所有候选并手动指定。文件在任意 MIDI 编辑器中把主旋律轨道改名为 `Melody`，也可以帮助程序准确选中它。

## 游戏映射

- 音键：`Z X C V B N M ,`
- 低音区：按住鼠标左键
- 半音：按住鼠标中键
- 高音区：按住鼠标右键
- 三种鼠标功能互斥；一次只按一个音键。

程序不检查游戏窗口和前台焦点。倒计时或演奏过程中再次按当前启停热键，会立即停止并释放程序当前按住的音键和鼠标键。

## 开发运行

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e . pyinstaller
python -m delta_harmonica
```

也可以运行 `run.ps1`。
