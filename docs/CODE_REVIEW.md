# v1.0.0 本轮修改与验证

日期：2026-09-16。保持 v1.0.0 正式版；未提交或推送 Git。

## 修改范围

- 交换夜莺、守望的显示名称，保留各自原曲、按键、时值与内部 ID；已有曲库记录读取时使用当前预设名称。
- 恢复任务片段完整流程提示，提示中的 F6 随当前热键更新。
- 倍速支持 0.25～1.50x、0.01x 精度和 6 个常用档位，输入非法值时还原并提示。试听和演奏使用同一速度范围。
- 每个 MidiSong 保存 speed_percent；切歌、重启、重新选轨保留。保存失败回退，播放过程中更改仅影响下次开始。
- 桌面置顶悬浮显示准备、倒计时、演奏及终止状态，展示会话快照速度和启停键；终止 4 秒后隐藏。默认开启、设置中可关，关闭软件时清理。
- 更新 README、功能说明、开发说明及三分钟宣传视频完整分镜、口播、字幕、录制清单、45 秒短版和发布文字草稿。

没有新增模型、MP3 转换、游戏注入、进程读取、账号或在线服务。没有把制作示例图片的外部脚本写成软件自带导出功能。

- 倍速控件改为按钮和弹出面板，包含快选、精确输入、长按加减和恢复原速；点击外部收起，停止长按重复。保存值、试听和演奏统一限定最高 1.5x。

- 新增浅色主题，默认深色，右上角太阳／月亮图标一键切换。Preferences.theme 记忆选择；主界面、音轨弹窗、倍速面板与消息框同步换色，overlay 保持自己的深色样式。主题仅更新外观，不重建演奏会话。

- 应用图标改为以守夜人口琴截图为参考制作的透明底古铜口琴图案；同一份多尺寸 ICO 用于 Qt 窗口和 EXE 资源，PNG 母图随源码保留。

## 验证结果

- 83 项自动回归通过，涵盖输入互斥、取消、时间轴、音轨选择与试听、热键、全部常用速度和自定义速度、每曲持久化、写盘失败、预设名称与原旋律、悬浮窗生命周期。
- 新增主题默认值、重启记忆、未知值回退、保存失败可见、弹窗即时换色及播放状态保留检查；逐张核对两套实际 Qt 界面。
- 源码语法及未使用导入检查、git diff --check 通过。
- 用 Qt 实际界面渲染核对主界面、倍速弹出面板、完整任务提示、音轨窗口和悬浮窗口；修正倍速按钮箭头可见性。
- 原生 Windows 悬浮窗口检查通过：WS_EX_TRANSPARENT、WS_EX_NOACTIVATE、WS_EX_TOPMOST、显示范围；软件窗口最小化时可见，显示过程未改变前台焦点。此检查不发送游戏输入。
- 正式 EXE 在独立目录与隔离用户数据下启动通过，不依赖外部 Python 或模型；第二实例退出并唤起原实例；正常关闭退出码为 0，解包目录清理通过。
- 包内没有旧音频识别模块、模型模块或隐藏诊断入口。EXE 正式标记和文件版本已核对。

未进行本轮游戏实录验收。独占全屏不能保证覆盖桌面悬浮窗，建议无边框或窗口模式；录屏需单独确认捕获到了悬浮提示。不能以回归通过宣称所有 MIDI 无漏音、旋律推荐必定正确或任务必定通过。

- 图标专项检查通过：PNG 资源、Qt 解码 9 种 ICO 尺寸、EXE 的 9 张内嵌图标与源 ICO 字节一致、包内资源完整、原生窗口大小图标句柄有效。更换图标后重新执行单文件启动、单实例及正常退出清理检查，均通过；未重复运行与图标无关的演奏回归。
