# Delta Harmonica｜2 分 30 秒宣传视频拍摄定稿

版本：v1.0.0 正式版。创作者：沙拉Sarada。

目标成片：横屏，02:30。正文旁白、字幕和镜头顺序按本稿执行；只需在发布前落实演示歌曲和下载地址。本文是拍摄执行稿，不是已经制作完成的视频。

本片要让观众看懂一句话：**选好 MIDI 音轨，回游戏拿出口琴，按 F6 开吹。**

## 一、确定下来的包装

**视频标题：** 三角洲口琴这样玩：导入曲谱，按 F6 开吹

**封面：** 游戏内手持口琴画面为主体，软件界面作为右下角小图。主文字两行：“选好曲谱”“F6 开吹”。角落小字：“Delta Harmonica · v1.0.0 正式版”。用金色口琴与浅色文字形成视觉重点，不再堆功能列表。

**风格：** 像开发者亲自演示给朋友看。直接、清楚，有操作、有声音。不开场念长标题，不放片头动画，不连续报参数，不要求观众先关注再看。

**署名：** 全片只使用“沙拉Sarada”。软件图标用现有透明底古铜口琴；主界面本身不额外加大图标。

**结尾固定用语：** “软件和使用说明放在简介。想用口琴吹哪首歌，评论区告诉我。”

## 二、开拍前统一好状态

### 1. 演示歌曲

- **歌曲 A：** 本片从导入到游戏演奏始终使用同一份 MIDI。可以使用已有的《加勒比.mid》；先确认实际旋律和游戏演奏效果，再确定片中显示的曲名。本文的“歌曲 A”是拍摄指代，不应原样放进成片。
- **歌曲 B：** 另一首已导入的 MIDI，只用来展示每首歌记住不同倍速，不需要额外录完整演奏。
- 开场截取歌曲 A 最容易辨认的一段 12 秒乐句；中段使用 A 另一段连续 15 秒演奏。尽量在乐句边界切入和切出。
- 如果 A 实际不适合口琴，就换成手上已经演奏满意的 MIDI；不要只因文件名熟悉而强行使用。

### 2. 软件状态

使用当前正式版单 EXE：`DeltaHarmonica.exe`。

| 项目 | 开场与教程段的值 |
| --- | --- |
| 主题 | 深色 |
| 启停键 | F6 |
| 启动延时 | 3 秒 |
| 歌曲 A 倍速 | 1.0x |
| 悬浮提示 | 开启 |
| 更多设置 | 初始收起，需要展示时再展开 |
| 署名 | 沙拉Sarada |

导入段使用尚未导入的 MIDI 路径，避免出现重复导入提示。已有记录可仅从列表移除后重新导入，原 MIDI 文件仍保留。不要清空整个曲库来摆拍。

先录好 A 的原速游戏素材，再录调速段。调速段才把 A 改成 0.92x，把 B 设成 1.10x。四个任务片段在拍摄时保留，不在主片实际删除；软件没有一键恢复预设按钮。

### 3. 录制与声音

- 横屏 1920×1080；优先使用能稳定录制的帧率，避免为了高帧率影响游戏声音。
- 游戏使用无边框窗口，软件与游戏放在同一屏幕。正式录之前先录 5 秒，回放确认右上角悬浮提示也被录到了；单独捕获游戏可能漏掉它。
- 游戏声音和麦克风分轨录制。游戏展示只用游戏口琴实声；音轨试听保留电脑钢琴音色。不要用原曲音频覆盖口琴，或把钢琴试听伪装成口琴效果。
- 每条素材前后多留 2 秒。软件界面操作录得慢一些，剪掉操作间的空等即可；游戏演奏镜头保持原速，不通过后期加速来压时长。
- 旁白按段单独录，不需要边操作边背台词。每句话录两遍，选择自然、咬字清楚的一遍。
- 文件窗口只保留必要的文件名区域；提前收起聊天窗口和通知。

## 七、剪辑执行规则

### 字幕和局部放大

- 旁白配同步字幕，每屏最多两行。中文一句过长时按语义换行，不把所有参数同时挤出来。
- 同步字幕放下方安全区域；功能重点字幕放左上或控件附近。避开游戏右上角悬浮提示。
- 金色用于点到为止的强调，浅色为主。不要给每句话都上弹跳、描边和闪光。
- 软件控件可做轻微放大；放大到能看清按钮文字就够。图像不能放大到字发虚。
- 进度条特写必须录真实更新，三个标注分别对应已播放、进度、剩余；不模拟拖动。

### 转场和声音

- 以直接切镜为主，软件与游戏切换可用短淡化，不加长转场。
- 第 01、06 镜头保持干净口琴原声。第 04 镜头旁白与钢琴试听错开。
- 第 08 镜头必须听见按 F6 后琴声停下来，不用后期静音制造停止效果。
- 不建议再加贯穿全片的音乐，观众主要是来听口琴效果。旁白音量统一，音轨切换时避免突然很响。

### 成片超时怎么减

先压缩鼠标移动和窗口等待，其次删去一个主题切换停顿，再缩短网页停留。不要靠加速游戏演奏、吞掉口播停顿或删掉真实倒计时凑时长。

若仍超过 02:35，将镜头 07 口播改为：“速度可以直接选，也能精确输入。每首歌会记住自己的倍速，切回来不用重设。”其余叙事不变。正常目标仍是 02:30。
