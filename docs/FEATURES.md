# Delta Harmonica v1.0.0 正式版功能说明

本说明对应 F6 / 3 秒 / 倍速面板界面。历史阶段文档与截图不代表当前软件。

## 主界面

保留软件名、bilibili 作者链接、热键就绪状态、MIDIShow 搜索、导入区域、曲谱列表、试听、倍速、选轨、更多设置、必要的状态与进度。

主界面不放版本副标题、倍速滑条或模式选择；倍速按钮展开后提供快捷档位、精确输入、加减微调和恢复原速。普通曲谱不显示额外的常驻操作段落；任务片段在列表下方显示完整流程提示，提示中的启停键随设置更新。

深色窗口默认 1240×820，最小 1040×700；空间不足时可以滚动。作者旁有 bilibili 小电视图标，“沙拉Sarada”链接到其 bilibili 主页。

## 外观主题

提供深色和浅色，默认深色。右上角热键状态旁有太阳／月亮按钮，悬停提示目标主题，点击立即切换并全局保存。主界面、音轨弹窗、倍速面板及软件消息框同步换色；原生系统文件选择窗口由 Windows 绘制。局内悬浮维持半透明深色。浅色采用浅灰白页面、白色卡片、深灰文字与蓝色操作按钮。切换不重新加载曲谱，不改动倍速、热键或演奏会话。

## 全部默认设置

| 设置 | 默认 | 可选 |
| --- | --- | --- |
| 启停热键 | F6 | F1～F12 |
| 延时 | 3 秒 | 0～30 秒 |
| 主题 | 深色 | 深色 / 浅色，右上角一键切换 |
| 倍速 | 每首歌 1.0x | 0.25x～1.50x，精确到 0.01x |
| 局内悬浮提示 | 开启 | 更多设置中开关 |
| 演奏安排 | 稳定播放 | 固定，界面和偏好中均无模式选项 |

F6 等启停键既负责开始也负责停止，长按仅触发一次。F12 使用独立键盘监听处理；其他功能键使用 Windows 热键注册。注册或监听不可用时显示提示，不静默失败。

倍速按 MIDI 的时间计算，1.0x 保留原曲变速。试听与游戏演奏均支持整个范围。点击倍速按钮展开面板，可快选 0.25 / 0.5 / 0.75 / 1.0 / 1.25 / 1.5x，或输入如 0.92x 后按回车。减号和加号每次调整 0.01x，长按连续调整；点击“恢复原速”回到 1.0x。快选后收起，微调时保持打开，点击外部收起。无效数值回退到上次有效值并提示。高倍速可能增加密集输入风险，不自动降速。

每首歌独立保存倍速，包括预设；切歌、重启或重新选轨后保留。写盘失败回退并提示。热键、延时、主题和悬浮提示开关全局保存。当前播放中更改倍速和延时下一遍生效，悬浮窗保留本次实际倍速。播放期间热键和曲谱操作锁定，停止后恢复；更多设置包含热键、延时和悬浮提示开关；主题在右上角切换。

## 导入、确认与音轨试听

支持选择多个本地 `.mid`、`.midi` 或拖放，扩展名大小写不敏感。按路径去重，排除远程链接与音频文件。支持 Type 0/1，包括极短片段；Type 2 明确拒绝。

每首有效导入文件都打开音轨对话框，即使只有一条轨道或推荐可信度很高，也需用户确认。多文件逐首确认，一首取消不阻止下一首。

对话框按“轨道 + 通道”列出非鼓候选，并显示：推荐标记、轨道/通道编号、名称、乐器类别与编号、音符数、时长、音域、单音率、密度，以及每行的试听按钮。默认选中推荐候选，重新选轨时优先选中之前选择。

每行试听按钮可以直接试听相应音轨；也可选中音轨使用底部试听/停止按钮。换轨会停止上一条音轨的声音。点击“使用所选音轨”或双击确认，关闭对话框会停止试听。对话框打开时不触发游戏演奏。

取消首次确认后保留“等待选择音轨”记录，不生成演奏数据；取消重新选轨保留原转换结果。无效文件或转换错误会提示，成功的其他文件继续可用。

## 转换与两种试听位置

自动推荐依据名称、乐器类别、单音结构、音域和密度等特征，不保证主旋律正确。解析快照在选轨和转换之间复用。

同一时刻的和弦保留最高音，重叠音截短；短于 25 毫秒的音过滤，曲首长空白通常只留最多 50 毫秒。根据当前 28 个可用音高（C3～C6，非连续半音阶）自动移调和调整八度，可能改变原调及局部音程效果。

选轨窗口试听原音高与复音结构；主界面试听适配后的单音旋律或任务片段。两者都使用 Windows 钢琴合成器，不是游戏口琴采样，也不发送游戏按键。设备失败、输出失败和关闭失败均显示原因。

没有音色切换、音量控件、录音、力度/踏板/弯音还原。

## 演奏、停止与提示

自行切回游戏、打开口琴，按设置中的热键，等待延时后开始。倒计时期间再次按键取消，演奏期间再次按键停止，再启动从头播放。

固定音键 `Z X C V B N M ,`；低音按住鼠标左键、半音按住中键、高音按住右键，普通音不配鼠标修饰键。各鼠标键互斥，同一时间只发送一个音键。长音按住，重复音重新按下，换音区先释放前一个音键。

稳定播放在既定时间轴内安排松键与音区准备，必要时缩短音尾，不自动降低倍速。密集输入显示一句简短风险提示；详细统计放在该提示的悬停文字，包含短音、间隔、准备时间、发送/跳过/迟到等信息。卡顿后已结束的音跳过，后续沿原定时间轴继续，不集中补发。

状态区域保留准备、倒计时、正在演奏、停止、完成和失败；进度条只能查看不能拖动。关闭窗口请求停止，等待按键清理；失败时保留提示供玩家处理。没有单独紧急停止键、焦点检查或自动切窗。

## 曲谱与预载片段

曲谱列表显示歌曲、当前音轨与状态，转换状态简化为可演奏、音符数和移调量。可移除任意条目，包括四个预载任务片段：

| 片段 | 角色 | 支持操作 |
| --- | --- | --- |
| 夜莺 | 佐拉 | 试听、倍速、延时演奏、移除 |
| 守望 | 老乔 | 同上 |
| 风起 | 唐吉 | 同上 |
| 破晓 | 佐拉 | 同上 |

预载片段使用固定任务按键与时值，不需要导入确认，也不提供换轨。移除写入曲库后重启不会重新出现，包括把四个片段全部移除的情况。没有新增预设管理或恢复入口。

软件不检查前置任务、不接取或提交任务、不判断奖励解锁结果。玩家自行完成游戏操作。

## 局内悬浮提示

状态右侧显示已播放时间、进度条和剩余时间（负号表示剩余）。时长使用本次实际倍速，倒计时不计入；依据演奏时间轴每 100 毫秒更新，长音和休止期间持续前进。停止或失败冻结当前位置，完成后显示满格和剩余 00:00，再次开始清零。进度条只显示进度，不支持拖动跳播。

默认开启。从准备演奏起显示歌名、倒计时／演奏状态、当前会话的实际倍速和启停键。停止、完成、失败保留 4 秒后隐藏；再次启动取消旧的隐藏计时。失败详情仍在主界面查看。可在更多设置关闭，不影响演奏。

悬浮窗显示在软件所在屏幕的右上角，鼠标穿透、不接受键盘焦点，不读取游戏进程，也不注入游戏。建议使用无边框或窗口模式，不能保证独占全屏显示。多屏时把主窗口放到游戏所在屏幕；未提供拖动定位或逐音字幕。

## MIDIShow 与网络

只保留 MIDIShow。关键词非空时打开 `https://www.midishow.com/search/result?q=关键词`，正确编码中文和特殊字符；为空打开首页。点击按钮和搜索框回车行为相同，浏览器打不开时状态栏提示。

不再使用 Midify、MIDI云、BitMidi 或百度限定站点搜索。不内置在线曲库、不自动下载；网站内容与收费规则由网站决定。

本地 MIDI 解析、试听、转换及演奏均无需联网。只有用户主动找谱或点击作者链接才打开外部页面。

## 数据与单 EXE

使用 `%LOCALAPPDATA%\DeltaHarmonicaNext` 保存 `library.json`、`preferences.json` 和 `converted` 内部演奏 JSON。预设与导入歌曲同属持久列表，不另加删除黑名单。

曲库和偏好格式保持第 2 版，不迁移更早格式。歌曲记录中的 speed_percent 保存该曲倍速，缺省为 100；偏好只保存热键、延时、主题和悬浮提示开关。第一次启动为 F6、3 秒、每首歌 1.0x、四个预载片段。原 MIDI、旧 JSON 和旧模型文件不会被自动删除。

导入只记录原文件路径；移除不删除原 MIDI 或转换文件。源文件移动后已有转换仍可演奏，重新选轨需要原文件。保存失败有提示，列表新增或删除不会在写盘失败后只改内存。

Windows x64 单 EXE 自动解包运行依赖，正常退出清理临时目录，保留用户数据。重复启动唤起已有窗口，移动或重命名 EXE 不改变数据位置。强制结束或断电可能留下临时目录并中断松键清理。

## 未提供

MP3/WAV 转 MIDI、视频识谱、模型下载、在线 AI、谱面预览/编辑、简谱/按键图导出、MIDI/音频导出、录音、完整多声部还原、暂停续播、循环、选段、自动连播、独立紧急停止键、焦点保护、托盘、账号、云同步、自动更新、开机自启。

此前简谱与按键图由独立脚本调用软件解析代码生成，尚未集成到 EXE。极大 MIDI 仍同步处理，可能短暂影响界面响应。
